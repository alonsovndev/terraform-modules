# Composition examples

These roots demonstrate module contracts and have plan-only mocked tests. Placeholder inputs, account permissions, artifact publication, and deployment prerequisites must be resolved before real use.

- [AWS static hosting](aws-static/README.md)
- [AWS containers and PostgreSQL](aws-container/README.md)
- [AWS Lambda HTTP API](aws-lambda/README.md)
- [GitHub OIDC](github-oidc/README.md)
- [Cloudflare Workers static hosting](cloudflare-static/README.md)

Providers and lock files belong to each root. No backend is configured for local validation; consuming projects must add their own remote state. See [deployment prerequisites](../docs/deployment.md). The complete deployment profiles are in [profiles](../profiles/README.md).
